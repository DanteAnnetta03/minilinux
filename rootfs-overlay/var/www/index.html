Upload a file (via scp)

Web upload is intentionally not supported to keep this system minimal. Transfer files using scp over SSH (port 22): 

# push a file from your machine into /home/mux:
scp ./localfile.txt mux@<minilinux-ip>:/home/mux/

# push a whole directory recursively:
scp -r ./myproject mux@<minilinux-ip>:/home/mux/

# pull from MiniLinux to your machine:
scp mux@<minilinux-ip>:/home/mux/notes.txt ./

GUI alternatives: Nautilus, Dolphin and Finder connect with sftp://mux@<ip>/home/mux. On Windows use WinSCP or FileZilla.
